The entire project was lapsed as well go check out the build process in JOURNAL.md

Most peope would create calculators using mathjs libraries or building upon existing foundations ( which barely takes an hour or 2) , but I wanted to do something different, something to challenge myself and learn all along the way , so that is why I created a complete multiparameter , programmable web base scientific calculator with my own custom engine, complete with its own tokenizer, shunting yard engine, stack evaluator, floating point domain errors and everyything in between.


The calculator is fully functional as of now, and I have patched up almost all of the remaining bugs or the errors,


Overall, I learnt a lot while making this amazing project and it has together been an wholesome experience, to build a common thing which already exists everywhere and we use it whether we know it or not.
